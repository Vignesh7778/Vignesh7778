### 🚜 1. CropLedger Desk
- **Problem Statement:** Lack of transparency and transaction security in agricultural supply chain tracking.
- **Solution:** Engineered a Java & Spring Boot backend with immutable transaction logging, MySQL relational storage, and a dynamic React desktop dashboard.
- **Security Protocols:** Enforced SHA-256 data hashing for ledger entries and JWT authentication for users.

### 📚 2. EduAura
- **Problem Statement:** Inefficient student performance tracking and fragmented learning resources.
- **Solution:** Developed a feature-rich learning portal using Angular for component modularity and Spring Boot for RESTful API orchestration.
- **Features:** Real-time analytics, dynamic quiz evaluation, and role-based access control (RBAC).

### 🤖 3. AI Agent
- **Problem Statement:** Manual execution of repetitive multi-step API workflows.
- **Solution:** Built an autonomous AI workflow assistant leveraging Python, custom prompt orchestration, and LLM APIs to handle autonomous task execution.
- **Deployment:** Containerized using Docker for reproducible execution environments.

### 🌐 4. Portfolio Website
- **Problem Statement:** Standard static portfolios lack developer personality and terminal responsiveness.
- **Solution:** Designed a ultra-responsive portfolio featuring dark terminal themes, micro-animations, fast asset rendering, and Vercel edge deployment.

### 🔐 5. Cyber Security Toolkit
- **Problem Statement:** Need for a lightweight diagnostic suite for basic security auditing and vulnerability identification.
- **Solution:** Authored a Python & Java security suite featuring multi-threaded port scanners, payload generator modules, and hash cracking verification utilities.
